# Q: Частково баг пропав, але залишилися сірі полоски на градієнтах

## Answer

Expanded from original query via graph vocab: [gradient, background, color, component, fallback, grid, lesson, native, preview, renderer, repeat, surface]. No-repeat fixed repeated edge colors but exposed a second issue: a valid native gradient was still painted over fallback backgroundColor, and GradientGrid plus MainScreen color preview had explicit gray borders. The shared GradientBackground now uses fallback only when no valid gradient exists, applies centered 102% native background overscan with no-repeat, and the two decorative borders were removed. React Native 0.86 parsers validate size, position, and repeat.

## Outcome

- Signal: corrected
- Correction: No-repeat alone was incomplete. Valid gradients must not retain the fallback background layer; native tiles need centered overscan, and decorative borders on gradient previews must be removed.
