# Q: Зробити всі градієнти одним продуманим компонентом і виправити верхній градієнт LessonViewer

## Answer

Expanded from original query via graph vocab: [gradient, background, component, lesson, viewer, preview, picker, card, color, native, render, style]. GradientBackground is now the only React Native UI background-gradient renderer. It paints on the owning View, TouchableOpacity, or Animated component; supports normalized stops, linear and radial gradients, layers, start and end conversion, opacity, fallbacks, and refs. LessonViewer now paints headerGradient directly on headerContainer. All prior expo-linear-gradient source call sites were migrated; SVG loader gradients remain separate because they are SVG paint definitions, not React Native background surfaces.
