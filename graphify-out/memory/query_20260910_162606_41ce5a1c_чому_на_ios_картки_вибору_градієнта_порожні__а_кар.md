# Q: Чому на iOS картки вибору градієнта порожні, а картки пар і завдань показують лише перший колір?

## Answer

Попередня нормалізація stops була недостатньою. Робочий preview мав явний flex-розмір, а проблемні елементи використовували вкладений absolute Expo LinearGradient. На iOS Fabric цей окремий native gradient layer міг отримувати нульові або несинхронізовані bounds. Виправлено структурно: GradientBackground генерує React Native experimental_backgroundImage і малює градієнт на тому самому View; GradientGrid, LessonCard і TaskCard застосовують цей фон безпосередньо до Touchable-картки. Додано fallback backgroundColor, точне перетворення кута, нормалізацію stops, контраст іконок та тест через реальний RN processBackgroundImage parser. 14 тестів і повний Expo iOS/Hermes export проходять.

## Outcome

- Signal: corrected
- Correction: Попередній висновок фокусувався на даних stops, але симптом залежав від layout: working preview мав bounds через flex, а порожні tile/card — вкладений absolute native view. Коректне виправлення переносить gradient paint на саму картку через Fabric backgroundImage.
