# Q: Виправити кольорові смуги по краях елементів з градієнтом на iOS та Android

## Answer

Expanded from original query via graph vocab: [gradient, background, color, colors, component, grid, lesson, native, picker, preview, renderer, surface]. The shared GradientBackground used React Native experimental_backgroundImage without experimental_backgroundRepeat. React Native 0.86 defaults missing repeat values to repeat, so fractional device pixels could render a repeated first or last gradient row along rounded card and preview edges. The centralized fix sets experimental_backgroundRepeat to no-repeat on native and backgroundRepeat to no-repeat on web. A regression test validates the value with React Native installed processBackgroundRepeat parser.
