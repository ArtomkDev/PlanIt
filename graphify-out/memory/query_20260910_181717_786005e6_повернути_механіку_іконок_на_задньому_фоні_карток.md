# Q: Повернути механіку іконок на задньому фоні карток уроку і завдання як було раніше

## Answer

Expanded from original query via graph vocab: [background, pattern, icon, card, lesson, task, positions, opacity, animated, layout, subject, phosphor]. Graphify показав BackgroundPattern у LessonCard і TaskIconPattern у Tasks. Відновлено стару композицію: шахова сітка повторюваної subject icon, кешовані позиції, поворот -12 градусів і fade-in; окремі великі іконки біля назви прибрано. LessonCard використовує opacity 0.25, TaskCard — старі 0.18 для білого foreground і 0.07 для темного, із collapse transform. Колір патерна залишається адаптивним до white-first foreground, щоб він був видимий і на білих картках. Патерни позначені декоративними для screen reader. 14 тестів та iOS/Hermes export пройшли.
