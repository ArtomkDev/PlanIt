# Q: програма лягає при добавлені пари: No safe area value available

## Answer

Expanded from original query via graph vocab: [attachment, image, preview, safe, area, provider, lesson, editor, modal]. Root cause: Root.jsx did not render a top-level SafeAreaProvider, so AttachmentImagePreview called useSafeAreaInsets without context when mounted from the lesson editor modal flow. Fixed by wrapping the full app content and navigation tree in SafeAreaProvider and adding a regression guard. Native guard tests pass 9/9, Babel transforms Root.jsx, and the iOS Hermes bundle exports successfully.
